# application-releve-photo
Création d'une application, sur téléphone Android et PC Windows, qui sert à localiser des photos sur les plans PDF d'un projet. Chaque photo est rattachée à un repère placé sur un plan, dans un local identifié. L'application fonctionne hors ligne et range les photos dans une arborescence Windows normalisée sur le serveur réseau partagé.
